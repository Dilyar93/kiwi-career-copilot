Delete your data

One-click local deletion

  1. Open the extension Side Panel.
  2. Select Settings.
  3. Select “Clear local data”.
  4. Confirm deletion.

This removes locally stored rules, commute origin, diagnostics and job history. To remove synced language/display preferences and the extension itself, uninstall it and use the browser’s sync-data controls where applicable.

The project has no operator server and therefore no remote account or server copy to delete.
