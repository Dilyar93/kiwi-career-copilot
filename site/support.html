Support

For support, privacy or security requests, use the publisher contact available from the extension’s Chrome Web Store listing.

Getting started

  1. Install Kiwi Job Search Enhancer from its browser extension listing.
  2. Open a supported job results page.
  3. Select the toolbar action to open the Side Panel.
  4. Add a filter or use Not interested on an individual job card.

Troubleshooting

  • If no controls appear, check the Current page adapter status and copy the count-only diagnostic summary.
  • If location fails, choose a known New Zealand place; the extension does not retry automatically.
  • If too many jobs disappear, turn on “Show filtered jobs” and inspect reasons.
  • Use Settings → Clear local data for a complete local reset.

See known limitations, data deletion and contact status.
