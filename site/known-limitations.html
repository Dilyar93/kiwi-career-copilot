Known limitations

  • The extension supports the exact www.seek.co.nz and nz.seek.com hosts.
  • Site DOM changes can temporarily degrade or disable filtering; broken adapters fail open.
  • Category rules run only when the current page exposes category data.
  • Distances are conservative straight-line estimates, not driving distance or a workplace address.
  • Remote, broad, unknown and unsafe-to-resolve locations remain visible.
  • Only one active commute origin and one active profile workflow are supported in v1.
  • Data is tied to the current browser profile unless the user explicitly exports it.
  • Desktop Chrome/Edge are the targets; mobile browsers and Firefox are not supported by v1.
  • The extension never fills a filtered page by loading more jobs.

Supported sites and browser behaviour can change. Verify important job and travel information on the original listing.
