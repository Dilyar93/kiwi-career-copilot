# V1 设计与实际实现回顾

本文件从当前仓库和项目作者确认的信息出发，说明 V1 原设计与最终产品的关系。它不修改原始需求文档。

## 总体判断

V1 的核心价值在 SEEK 上成立：用户可以在当前搜索结果中排除不需要的岗位，并跨页面保存状态。主要偏差是 Trade Me 支持没有成为可靠产品能力，而原文中的部分发布、合规和双浏览器目标缺少可验证记录。

## 对照

| 原设计 | 实际结果 | 分类 | V2 处理 |
|---|---|---|---|
| 同时支持 SEEK 与 Trade Me Jobs | SEEK 可用；Trade Me 上线后确认不可可靠使用 | 已偏离 | V2 明确 SEEK-only，删除运行入口；遗留类型和翻译后续清理 |
| 关键词、类别、公司负向筛选 | 已实现 | 已实现 | 保留并回归测试 |
| 不感兴趣、撤销、已看过、跨页状态 | 已实现 | 已实现 | 保留 |
| 保守距离筛选、未知地点不自动隐藏 | 已实现 | 已实现 | 保留 |
| 动态加载和 SPA 页面处理 | 已实现并有 fixture/E2E 覆盖 | 已实现 | 继续复用生命周期逻辑 |
| Side Panel 管理规则与设置 | 已实现 | 已实现 | 功能保留，交互和信息架构在 V2 重做 |
| Chrome 与 Edge 最低版本支持 | Chrome 已发布；Edge 只有构建能力，真实发布未确认 | 部分实现 | 当前不以商店发布为主线 |
| 发布前取得平台许可或法律意见 | 仓库没有相关完成记录，但 V1 已发布 | 过程偏离 | 不推测当时过程；V2 发布前重新评估 |
| Manifest 仅申请最小权限 | V1 基本符合；V2 为本地 Agent 增加了 loopback host permission | 版本演进 | 在 V2 架构中单独说明 |
| 建议的目录、接口和 Options 页面 | 实际实现采用更紧凑的模块和 Side Panel，没有独立 Options 页面 | 实现偏离 | 不为匹配旧文而重构；只按当前产品边界拆分 |
| Adapter contract 同时服务两个网站 | 当前运行时只有 SEEK adapter；仍有 Trade Me 类型/i18n 遗留 | 部分实现 | 先清理声明，再在真实新增网站时验证抽象 |
| 双站点 contract、集成、E2E 和 live smoke test | SEEK 有自动化覆盖；Trade Me 未形成可靠验收 | 未完整实现 | 不补 Trade Me 测试 |
| `0.8.0` release readiness | 是历史快照；当前 package 已为 `2.0.0` | 已过期 | 归档，不作为当前发布结论 |

## 已知代码遗留

- `SiteId`、存储 schema 和部分翻译仍包含 `trademe-jobs-nz`。
- 历史 `.output` 中可能存在 `0.8.0` Chrome/Edge zip，不能代表当前可发布产物。
- 根包描述仍偏向 V1 “filter”，与 V2 产品定位尚未完全统一。

这些属于后续整理任务。除非影响当前 SEEK 产品体验，不需要为了历史一致性立即重写。
