# V1：SEEK 列表结果增强器

V1 是已经发布到 Chrome Web Store 的浏览器扩展，主要解决 SEEK 原生搜索难以表达“我不想看到什么”的问题。V2 保留其可用的筛选能力，但不再继续扩展 V1 产品线。

## 产品范围

V1 面向 SEEK 搜索结果列表，提供：

- 关键词、职位类别和公司排除规则。
- 不感兴趣、已看过和跨页状态。
- 基于新西兰地点数据的保守距离筛选。
- Side Panel 设置、撤销、诊断、数据导入导出和中英文界面。

它不负责读取完整 JD、分析候选人匹配度、生成申请材料或管理求职过程；这些属于 V2。

## 当前结论

| 范围 | 状态 | 结论 |
|---|---|---|
| SEEK 列表筛选 | 已实现 | 现有代码和自动化测试覆盖主要路径，V2 必须保持兼容。 |
| Chrome Web Store | 已发布 | 由项目作者确认；仓库未保存商店审核过程。 |
| Trade Me Jobs | 已退役 | 发布后发现不可可靠使用；V2 已移除运行入口，不再宣称支持。 |
| Edge | 未确认 | 仓库能生成 Edge 构建，但没有发布或真实环境验收记录。 |
| 平台许可与法律前置条件 | 无完成记录 | 原设计把它列为发布门槛，但仓库中没有可验证的证明材料。 |

完整版本快照包括 [产品定义](product.md)、[实际架构](architecture.md) 和 [实现回顾](implementation-review.md)。原始文档保存在 [archive](archive/README.md)，仅供追溯。

当前线上 V1 对应的[商店文案与截图](../../store/chrome/README.md)和[公开支持与政策页面](../../site/README.md)继续保留，用于维护线上版本；它们不是当前 V2 源码的发布说明。

## 对 V2 的约束

- SEEK 现有筛选能力不能因 V2 改造而回归。
- 不恢复失效的 Trade Me 实现；未来网站必须通过独立 adapter 接入并重新验证。
- V1 的 Side Panel 信息架构不是 V2 必须继承的产品设计。
- V1 的旧版本号、发布步骤和权限说明不得用于描述当前 V2。
