# V1 产品快照

状态：冻结。本文按当前代码还原 V1 实际交付的产品，而不是复述原始企划。

## 产品定义

Kiwi Job Search Enhancer V1 是一个面向新西兰 SEEK 搜索结果页的 Chrome 扩展。它补充 SEEK 缺少的负向筛选和个人状态管理，让用户减少重复浏览明显不合适的职位。

## 用户问题

- SEEK 原生筛选适合表达“我想找什么”，不便表达“不想看到什么”。
- 用户会重复看到不相关关键词、类别、公司或已明确放弃的岗位。
- 搜索地点不等于可接受通勤距离，且新西兰地点文本存在宽泛或歧义。
- 无限滚动和跨页浏览让“看过/忽略过”的状态难以保持。

## 实际功能

### 负向规则

- 按职位标题、摘要等卡片文本进行关键词排除。
- 排除职位类别和公司。
- 支持前缀 wildcard 规则。
- 规则保存在扩展存储中，并可导入导出。

### 职位状态

- 将职位标记为不感兴趣并隐藏。
- 短时撤销最近操作。
- 记录已看过状态，并在翻页、刷新和重新打开时恢复。

### 距离

- 使用浏览器定位或用户手工选择的起点。
- 解析新西兰地点并计算保守距离。
- 只有在置信度足够且保守最小距离明确超过阈值时自动隐藏。
- 未知、宽泛、多地点、remote/hybrid 等情况优先保留并提示，而不是误删。

### 界面与数据

- Side Panel 提供当前页统计、规则、距离、不感兴趣列表、设置和诊断。
- 支持英文和简体中文。
- 本地处理和保存主要状态，不要求用户账号或云端后端。

## 用户主流程

```text
安装扩展
→ 打开 SEEK 搜索结果
→ 在 Side Panel 设置排除规则和可选距离
→ 页面自动隐藏明确不符合条件的卡片
→ 用户继续浏览、标记不感兴趣或撤销
→ 设置与职位状态跨页保留
```

## 安全与产品边界

- 只处理用户当前打开页面已经展示的 DOM，不做后台批量抓取。
- 不自动申请、不读取完整候选人资料、不调用 AI。
- 规则匹配失败时应 fail open，保留职位而不是误隐藏。
- 地点不确定时不做自动距离排除。
- 正常功能不需要账号、远程数据库或上传个人求职数据。

## 非功能要求

- 动态加载、无限滚动和 SPA 页面变化后继续工作。
- 页面装饰不破坏 SEEK 原有链接、按钮和布局。
- 存储数据可导出、导入和清除。
- 关键交互可键盘操作，并提供可理解的状态文案。
- Adapter 失效时停止过滤并提供诊断，不静默隐藏错误结果。

## 已知限制

- Trade Me Jobs 曾在原需求中承诺，但没有成为可靠的实际能力，现已退役。
- 站点 DOM 变化仍可能破坏提取，需要 fixture、E2E 和真实 smoke test 配合维护。
- Edge 构建存在，但没有可确认的商店发布状态。
- V1 Side Panel 以功能模块组织；它不适合作为 V2 一体化求职产品的信息架构。
