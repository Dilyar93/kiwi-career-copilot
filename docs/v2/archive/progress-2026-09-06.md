## 当前安全边界

- 服务仅绑定 `127.0.0.1`，校验共享 token 和精确 extension identity。
- Content Script 不访问本地服务；只有 Side Panel 可以请求 loopback API。
- JD 被标记为不可信输入，输出必须通过 Pydantic/evidence validator。
- Hard blocker 禁止材料生成；未知或未确认 evidence ID 会被拒绝。
- 私人数据库、API Key、生成报告和个人导入文件不提交 Git。

5. 完成 Gate A 手工检查和最终演示文档。
