# NZ location data attribution

Contains data sourced from Toitū Te Whenua Land Information New Zealand, licensed for reuse under CC BY 4.0.

Data has been filtered, normalised and supplemented with aliases. Polygon geometry was converted to an interior representative point and a conservative covering radius; raw polygons are not distributed.
